# GitHub Users Viewer

A simple JavaScript project that uses the GitHub REST API to fetch and display GitHub users. The application demonstrates the use of the Fetch API, Async/Await, DOM manipulation, and basic error handling.

##  Features

- Fetches GitHub users from the GitHub API.
- Displays user avatars.
- Shows GitHub usernames.
- Provides a link to each user's GitHub profile.
- Uses Async/Await for asynchronous programming.
- Includes error handling using try-catch.

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- GitHub REST API
